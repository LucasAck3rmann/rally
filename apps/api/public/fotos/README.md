# Fotos de exemplo (seed)

Imagens usadas **apenas no seed de desenvolvimento**, exportadas do arquivo de
design [Rally — Quadras de Areia](https://www.figma.com/design/M6neeXlII8VbrxV5GOpo5Z)
para que o app rode com as mesmas fotos das telas.

Em produção as fotos de quadra são enviadas pelo estabelecimento e vão para o
S3/CloudFront (ver `docs/arquitetura.md`) — nada aqui é servido em produção.
